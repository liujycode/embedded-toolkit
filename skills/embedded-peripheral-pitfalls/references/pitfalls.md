## dma — DMA（8 坑）

| 坑 | 症状 | 对策 |
|---|---|---|
| 想连续采集/接收没开循环模式 | 搬完一次就停，之后数据全丢 | 连续场景打开循环模式；单次模式下每次传输结束要重设数量寄存器并重新启动，别只初始化一次 |
| 乒乓缓冲没用对 HT/TC 分割点 | 半边数据被覆盖/撕裂 | 半传输中断处理前半缓冲、全传输中断处理后半缓冲，两缓冲交替写入；HT/TC 分割点要对应该模式的缓冲边界 |
| 内存到内存拷贝地址没自增 | 只有第一个单元有数据，其余不变 | 源端和目标端两侧都开地址自增（MINC/PINC），否则指针从不前进只在首地址打转 |
| 源/目标传输宽度与指针类型不符 | 数据错位或被截断，数值像被压缩 | 两边传输宽度一致（按字节数组搬就配 8 位），别让指针与传输宽度对不上 |
| 突发长度与 FIFO 阈值矛盾 | 突发被拆散或报配置错，高带宽源欠载 | 使能突发的前提是传输宽度和 FIFO 阈值能承载该突发长度；把 FIFO 阈值和数据大小配到与突发匹配 |
| 外设请求线/DMAMUX 源选错 | DMA 一直不触发或误触发 | 对照该系列手册的 DMA 请求映射表重选请求源；带 DMAMUX 的新系列重点核对通道选择配置 |
| 高带宽流优先级太低欠载 | 高带宽外设偶发丢数、传输被拖长 | 按带宽给流/通道分优先级，高带宽传输提优先级并合理分级；ISR 里快速清标志别堵塞新请求 |
| 标志清除顺序/口径用错（写 1 清） | 传完中断不再进或一直停在完成态 | 先清标志再改配置再启动；这类标志是写 1 清零，别用写 0 或读清的方式 |

- **想连续采集/接收没开循环模式** 依据：STM32 参考手册（如 RM0440，DMA 控制器循环/普通（单次）模式与数量寄存器 NDTR 重装机制）
- **乒乓缓冲没用对 HT/TC 分割点** 依据：STM32 参考手册（如 RM0440，DMA 半传输/全传输中断标志 HT/TC 语义）
- **内存到内存拷贝地址没自增** 依据：STM32 参考手册（如 RM0440，DMA 源/目标地址自增位 MINC/PINC）
- **源/目标传输宽度与指针类型不符** 依据：STM32 参考手册（如 RM0440，DMA 传输宽度 PSIZE/DSIZE）
- **突发长度与 FIFO 阈值矛盾** 依据：STM32G4 参考手册 RM0440；STM32H7 参考手册 RM0433
- **外设请求线/DMAMUX 源选错** 依据：STM32G4 参考手册 RM0440；STM32H7 参考手册 RM0433
- **高带宽流优先级太低欠载** 依据：STM32 参考手册（如 RM0440，DMA 通道/流传输优先级 PL）

|---|---|---|

| 优先级分组理解错 | 嵌套行为和预期不符 | 全工程统一一个分组，只初始化一次 |

## 配置口诀

配置口诀：使能时钟 → 配 GPIO → 配外设 → 配中断/NVIC → 使能外设，顺序不能乱。每配一个外设，回读关键寄存器确认写入生效。
