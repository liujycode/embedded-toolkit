| 坑 | 症状 | 对策 |

## sd — SD 卡 / FATFS（5 坑）

| 坑 | 症状 | 对策 |
|---|---|---|
| 上电初始化时钟超过 400kHz | 卡初始化失败、CMD0 无响应 | 初始化阶段把时钟压到 400kHz 以下进入卡模式（SPI/SD），身份识别完成后再提高时钟 |
| diskio 实现层出问题 | 挂载失败、一直 busy、读写成块错 | 先查 disk_initialize/disk_status/disk_read 的返回值和底层实现，FatFs 挂载失败 90% 出在 diskio 层 |
| DMA 与缓冲对齐 | SD DMA 搬出错、数据错位 | 缓冲地址与长度对齐到块/字边界，必要时用对齐缓冲或二次拷贝 |
| 写保护/热插拔重挂载 | 换卡后不识别、写失败、读不到新卡 | 实现卡插入/移除检测并在插拔后重挂载，处理写保护，挂载前重新初始化卡 |
| 扇区大小错配 | 读写错位、部分数据丢 | 确认卡真实扇区大小（常见 512），FatFs 用对应扇区大小配置，底层块读写 length 与扇区对齐 |

- **上电初始化时钟超过 400kHz** 依据：SD 卡物理层规范（SD Physical Layer Simplified Specification）
- **diskio 实现层出问题** 依据：FatFs 官方文档（diskio 层）
- **DMA 与缓冲对齐** 依据：SD 卡物理层规范（SD Physical Layer Simplified Specification）
- **写保护/热插拔重挂载** 依据：FatFs 官方文档（diskio 层）
- **扇区大小错配** 依据：SD 卡物理层规范（SD Physical Layer Simplified Specification）；FatFs 官方文档（diskio 层）

## sensor-bus — 单总线 / 数字传感器（5 坑）

| 坑 | 症状 | 对策 |

| 1-Wire 微秒时序被中断打断 | 偶发读不到器件、时序失败 | reset/时隙等微秒级关键段关中断或屏蔽高优先级中断，配 DWT 周期级延时保证时序 |

- **上拉/寄生电源供电** 依据：Dallas Semiconductor 1-Wire 协议规范；DS18B20 数据手册；下一步：embedded-timing-calc rc-settle --r <R_ohm> --c <C_F>

## tim — 定时器（9 坑）

| 坑 | 症状 | 对策 |
|---|---|---|
| ARR/PSC 与实际频率对不上 | 周期差几倍 | 公式反算回读：F = PCLK×(分频)/(PSC+1)/(ARR+1) |
| 只改 ARR 没产生更新事件 | 新周期下个周期才生效 | 改完软触发 EGR 或等更新中断同步 |
| 互补输出没配死区/刹车 | 上下管直通炸管子 | 功率级必配 BDTR 死区；电机语境转电机专家 |
| 编码器模式读数跳变 | 计数异常 | 查 TI1/TI2 极性与滤波器；机械问题转电机专家 |
| 定时器配完忘了启动 | 配置全写进去了，就是不计数 | 查 CR1 的 CEN 位——最后一步必须启动计数器 |
| 多定时器不同步 | 各自起跑相位差、触发关系乱 | 用主从模式：主定时器 TRGO 输出，从定时器选对应 ITR 源 + 触发模式 |
| 刹车输入 break 没弄对 | PWM 意外关闭或锁死关不掉 | 核对 break 使能位/极性，刹车触发后要清 BRK 标志或重新去刹车才能恢复输出 |
| 重复计数器 REP 与触发同步没对齐 | 每 N 次才更新一次、触发不同步 | 重复计数模式下更新事件/触发与 REP+1 对齐；需要每次更新就同步时把 REP 设 0 |
| 互补死区数值算错 | 死区波形不对、有直通风险 | 死区时间由 DTG 位域按分频与 tDTS 计算公式得出——先查相应用作死区计算的数值坑，别拿印象值手填（用 embedded-timing-calc deadtime 换算） |

- **ARR/PSC 与实际频率对不上** 依据：STM32 参考手册（如 RM0090，通用定时器章节）；下一步：embedded-timing-calc timer --pclk <APB_Hz> --freq <Hz>
- **只改 ARR 没产生更新事件** 依据：STM32 参考手册（如 RM0090，通用定时器章节）
- **互补输出没配死区/刹车** 依据：STM32 参考手册（如 RM0440，TIM 章节）；下一步：embedded-timing-calc deadtime --fsw <fsw_Hz> --dt <dt_s>
- **编码器模式读数跳变** 依据：STM32 参考手册（如 RM0440，TIM 章节）
- **定时器配完忘了启动** 依据：STM32 参考手册（如 RM0090，通用定时器章节）
- **多定时器不同步** 依据：STM32 参考手册（如 RM0440，TIM 章节）
- **刹车输入 break 没弄对** 依据：STM32 参考手册（如 RM0440，对应外设章节）
- **重复计数器 REP 与触发同步没对齐** 依据：STM32 参考手册（如 RM0440，对应外设章节）；下一步：embedded-register-lookup set <TIMx>.RCR REP=<重复次数> --chip <芯片>

## uart — USART / UART（8 坑）

| 坑 | 症状 | 对策 |

| 波特率寄存器手算错 | 乱码且固定错位 | 用 HAL 算或读回 BRR 验证，误差 <2% |

| DMA+空闲中断：IDLE 标志顺序错 | 不定长接收失效 | 先清 IDLE 再使能；用 NDTR 算实际长度 |

| 硬流控 RTS/CTS 接反 | 只发不收、丢数据 | 核对 RTS/CTS 与对端接线（RTS↔CTS 交叉），示波器查 CTS 是否常拉低、使能位置 |

- **DMA+空闲中断：IDLE 标志顺序错** 依据：STM32 参考手册（如 RM0090，USART 章节）

- **RS485 方向脚切换时机** 依据：STM32 参考手册（如 RM0090，USART 章节）

- **AT 模组透传模式退不出** 依据：STM32 参考手册（如 RM0440，对应外设章节）

## usb — USB 设备（6 坑）

| 坑 | 症状 | 对策 |
|---|---|---|
| USB 时钟没校准到 48MHz | 设备枚举失败或时好时坏、传输偶发超时 | 用 HSI48 作 USB 时钟时开启 CRS 自动校准，把时钟误差控制在 ±0.25% 内；必要时以 SOF 或外部参考信号同步 |
| DP 上拉/软断开复位没做 | 插拔后设备不能重新枚举，host 识别不到 | 热重连前先把 DP 上拉去掉做软断开，延迟一段时间后再恢复上拉，让 host 重新检测设备 |
| 端点0描述符长度/分包处理不当 | host 枚举失败，拿不到设备描述符或中途报错 | 按 USB 规范处理控制传输的 IN 包分帧：设备描述符前 64 字节要成包发送，设置地址与配置类请求要正确处理未完成包和实际长度 |
| 端点缓冲区对齐/大小不匹配 | 端点收发异常、收错数据或 FIFO 打开失败 | 按参考手册核对每个端点的缓冲基地址对齐（字对齐）与分配的缓冲区大小，配置寄存器要落在允许范围内 |
| CDC 虚拟串口 Windows 枚举/驱动问题 | Win 里看不到虚拟串口或设备感叹号 | 核对 CDC 描述符（接口数、端点、配置），设备名/厂商 ID 避开已知冲突，必要时让 Windows 重新枚举（卸载驱动或换 USB 口） |
| 供电/VBUS 检测没处理 | 插上没反应，或插拔检测不到 | 检测 VBUS 电平（或按所接 USB 口协商电流）决定何时使能内部上拉启动枚举；欠载时不要贸然进枚举 |

- **USB 时钟没校准到 48MHz** 依据：STM32 参考手册（如 RM0440，时钟控制与 USB 章节）
- **DP 上拉/软断开复位没做** 依据：STM32 参考手册（如 RM0440，USB 章节）
- **端点0描述符长度/分包处理不当** 依据：USB 2.0 规范（枚举流程）；STM32 参考手册（如 RM0440，USB 章节）；下一步：embedded-register-lookup lookup <USB>.EP0R --chip <芯片>
- **端点缓冲区对齐/大小不匹配** 依据：STM32 参考手册（如 RM0440，USB 章节）
- **CDC 虚拟串口 Windows 枚举/驱动问题** 依据：USB CDC 类规范；USB 2.0 规范（枚举流程）
- **供电/VBUS 检测没处理** 依据：USB 2.0 规范（供电与检测章节）

## 配置口诀

配置口诀：使能时钟 → 配 GPIO → 配外设 → 配中断/NVIC → 使能外设，顺序不能乱。每配一个外设，回读关键寄存器确认写入生效。
