# 外设配置坑清单（人类可读全量版）

> 本文档是 assets/pitfalls.json 的人类可读对照版，内容同源。检索用 `scripts/pitfalls.py`（结构化），通读用本文档。
> 维护纪律：改任何坑位，**先改 pitfalls.json（权威源），再同步本文档**。

## 配置口诀

**使能时钟 → 配 GPIO → 配外设 → 配中断/NVIC → 使能外设**，顺序不能乱。每配一个外设，回读关键寄存器确认写入生效。

## RCC / 时钟

| 坑 | 症状 | 对策 |
|---|---|---|
| 外设时钟没开就访问寄存器 | HardFault（PRECISERR）或写入无效 | 使能后回读外设寄存器验证；宁可多开不可漏 |
| PLL 超频电压档没跟上 | 系统不稳/起不来 | 查 H7/F4 的 VOS 电压档位与频率对应表 |
| HSI 精度当晶振用 | UART 长距离通信乱码 | HSI ±1% 精度，UART 误差>2% 误码；换 HSE |
| 定时器时钟源选错（APB×1 vs ×2） | 定时周期差一倍 | APB 分频>1 时定时器时钟 = PCLK×2 |

## GPIO

| 坑 | 症状 | 对策 |
|---|---|---|
| 复用没切 AF 模式 | 外设完全无输出 | 读 MODER/AFR 回读确认 |
| I2C 引脚配成推挽 | 总线卡死/烧器件 | I2C 必须 AF+开漏+上拉（4.7k 典型） |
| 非 FT 引脚接 5V | 电平不匹配/引脚损坏 | 查 datasheet 的 FT（five volt tolerant）标记 |
| 模拟脚没设模拟模式 | ADC 采集噪声大 | analog 模式并关施密特触发器 |

## EXTI / NVIC 中断

| 坑 | 症状 | 对策 |
|---|---|---|
| 标志位没清/清错位置 | 中断只进一次或狂进 | 严格按 RM 清除顺序（EXTI 的 PR 写 1 清零） |
| 优先级分组理解错 | 嵌套行为不符预期 | 全工程统一一个分组，只初始化一次 |
| 高优先级中断里做慢活 | 低优先级饿死/看门狗复位 | ISR 只做取数据+置标志，活儿给主循环/任务 |
| FreeRTOS 超 MAX_SYSCALL 优先级调 API | 直接挂死 | 优先级数值 ≥ configMAX_SYSCALL（数值大=优先级低） |

## 定时器

| 坑 | 症状 | 对策 |
|---|---|---|
| ARR/PSC 与实际频率对不上 | 周期差几倍 | 公式反算回读：F = PCLK×(分频)/(PSC+1)/(ARR+1) |
| 只改 ARR 没产生更新事件 | 新周期下个周期才生效 | 改完软触发 EGR 或等更新中断同步 |
| 互补输出没配死区/刹车 | 上下管直通炸管子 | 功率级必配 BDTR 死区；电机语境转电机专家 |
| 编码器模式读数跳变 | 计数异常 | 查 TI1/TI2 极性与滤波器；机械问题转电机专家 |

## ADC

| 坑 | 症状 | 对策 |
|---|---|---|
| 采样时间太短 | 数据抖/精度差 | 按信号源内阻配采样周期（datasheet 最小采样时间表） |
| 没做校准（F1/F3） | 全体数据偏移 | 上电先跑校准例程 |
| 规则组/注入组概念混 | 采集顺序乱 | 常规用规则组；注入组=高优先级插队（电机相电流归电机专家） |
| VREF 没接好/参考电压漂 | 数据整体比例错 | 查 VDDA/VREF+；软件用内部 VREFINT 反算 |
| DMA 缓冲区不可达（H7 DTCM） | DMA 静默不搬 | 缓冲放 AXI SRAM/D2 域或查总线矩阵 |

## USART / UART

| 坑 | 症状 | 对策 |
|---|---|---|
| 波特率寄存器手算错 | 乱码且固定错位 | HAL 算或读回 BRR 验证，误差 <2% |
| 只开中断没开 USART 时钟/引脚 | 完全无响应 | 第一层配置回读 |
| DMA+空闲中断 IDLE 标志顺序错 | 不定长接收失效 | 先清 IDLE 再使能；NDTR 算长度 |
| 9 位模式/校验位两端不一致 | 偶发字符错乱 | 两端逐位核对：字长/校验/停止位 |

## I2C

| 坑 | 症状 | 对策 |
|---|---|---|
| 上拉电阻没接/太大 | SDA/SCL 上不去高电平 | 示波器看上升沿；4.7k 起步按总线电容调 |
| 从机地址 7 位/8 位写法混 | NAK（地址不对） | 看清 HAL API 约定（7 位是否需左移） |
| 总线被从机拉死 | SDA 一直低 | 9 脉冲解救时序或断电重启外设 |
| 读 SR 后必须读 DR（老 F1） | 卡在 EV 状态 | 严格按状态机图（G4/H7 已简化） |
| 时钟拉伸没考虑 | 快从机数据丢 | 查从机 datasheet 速率（400k/1000k） |

## SPI

| 坑 | 症状 | 对策 |
|---|---|---|
| CPOL/CPHA 配错 | 全错位或全 0xFF | **先读从机手册时序图**，四组合试错是浪费生命 |
| 片选拉高太早 | 最后一字节丢失 | 等 BSY 清零再拉高 CS |
| 16 位/8 位帧格式混 | 高低字节交换 | 查 DFF/DS 位配置 |
| 全双工只写不读 | RX 溢出 OVR | 写同时读 DR（或开 RX DMA）清溢出 |

## CAN / FDCAN

| 坑 | 症状 | 对策 |
|---|---|---|
| 位时序段配错（采样点） | 偶发错误帧 | 采样点 75-87.5%，用位时序计算器 |
| 过滤器没配对 | 收不到任何报文 | 先全收（掩码全 0）验证链路再收紧 |
| TX 邮箱满没等 | 发送丢帧 | 查邮箱空标志或 FIFO 模式 |
| 终端电阻缺失 | 边沿畸变通信不稳 | 总线两端 120Ω，示波器看波形 |

## 维护纪律

- 遇到新坑：先复现确认 → 回填 pitfalls.json → 同步本文档（注明芯片型号与寄存器证据）。
- 不收录一次性灵异现象。
